# Conventions

_Пополнять по мере появления кода._

- Коммиты: обычный imperative-стиль, без строгого формата (соло-проект).
- C# (`extractor/`): нативные P/Invoke-обвязки над StormLib изолировать в `Extractor.Mpq`, не размазывать `DllImport` по всему решению.
- PHP/Symfony (`web/`): Doctrine migrations — единственный источник изменений схемы БД, руками таблицы не трогать.
- Комментарии в коде — только по факту, без рассуждений/истории попыток (личное правило пользователя, см. `IDENTITY.md`).
- Временные/скачиваемые файлы (архивы, распакованные .deb и т.п.) класть в `.tmp/` внутри репозитория (в `.gitignore`), не в `/tmp` — по явному указанию пользователя.
- PowerShell-скрипты (`extractor/scripts/*.ps1`) — только чистый ASCII, никаких `—`/кавычек-ёлочек/кириллицы в коде и комментариях. Windows PowerShell (`powershell.exe`, не `pwsh`) без UTF-8 BOM читает `.ps1` в системной ANSI-кодировке; не-ASCII байты внутри строки превращаются в мусор и ломают парсер ("missing terminator") — реальный случай, см. `gotchas.md`.
